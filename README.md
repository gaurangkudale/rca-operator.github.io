# rca-operator.github.io

Website for the [RCA Operator](https://github.com/gaurangkudale/RCA-Operator) project — a Kubernetes-native incident correlation operator with released Phase 2 OpenTelemetry ingest, topology graphs, durable incident state, and an embedded dashboard.
